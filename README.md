# 🏓 PONG CMD 8-BIT

Um jogo clássico de Pong feito em **Batch (.bat) + PowerShell**, rodando diretamente no Prompt de Comando do Windows! Conta com trilha sonora 8-bit em loop, efeitos sonoros nativos, 6 níveis de dificuldade contra a máquina, modo para 2 jogadores totalmente personalizável e tela de créditos animada.

---

## ⚠️ OBRIGATÓRIO: Como Instalar e Abrir

Para que a trilha sonora funcione e o jogo não apresente erros, **siga rigorosamente estes passos**:

1. Vá até a aba **Releases** (no menu lateral direito desta página) e baixe o arquivo **`.zip`** da versão mais recente.
2. **🚨 EXTRAIA PARA O DESKTOP (ÁREA DE TRABALHO):**
   * Clique com o botão direito sobre o arquivo `.zip` baixado e selecione **Extrair Tudo...**.
   * Escolha a sua **Área de Trabalho (Desktop)** como destino da extração.
   * *Não abra o `Pong.bat` de dentro do arquivo `.zip` nem em pastas temporárias, pois a trilha sonora não será encontrada.*
3. Verifique se o arquivo **`Pong.bat`** e a pasta **`Pong_Assets`** (onde fica a música `Pong_trilha.wav`) estão juntos no mesmo local.
4. Dê um duplo clique no arquivo **`Pong.bat`** para iniciar o jogo.

---

## 🎮 Passo a Passo: Como Jogar

1. **Menu Principal:** Use as `Setas para Cima/Baixo` (ou `W` / `S`) para navegar entre as opções e aperte `ENTER` para confirmar:
   * **Modos contra o Bot:** Escolha entre *Fácil, Médio, Difícil, Muito Difícil, Insano* ou *Impossível*.
   * **2 Jogadores (2v2 Local):** Desafie outra pessoa no mesmo teclado.
   * **Créditos:** Veja a animação de créditos do jogo.
2. **Configurar Partida:**
   * Digite o nome dos jogadores antes de iniciar (ou apenas aperte `ENTER` para manter os nomes padrão).
   * No modo **2 Jogadores**, escolha também a **velocidade da bola** (*Lenta, Normal, Rápida* ou *Turbo*) e a **cor da raquete** de cada jogador (*Verde, Ciano, Amarelo, Vermelho, Magenta* ou *Branco*).
3. **Objetivo:** Rebata a bola e marque pontos contra o adversário. Vence quem fizer **12 pontos** primeiro!

---

## 🕹️ Resumo dos Controles

| Ação | Modo 1 Jogador | Modo 2 Jogadores (2v2) |
| :--- | :--- | :--- |
| **Mover Jogador 1 (Esquerda)** | `W` / `S` ou `Setas` | `W` (Cima) / `S` (Baixo) |
| **Mover Jogador 2 (Direita)** | *(Controlado pelo Bot)* | `Seta para Cima` / `Seta para Baixo` |
| **Pausar / Continuar** | `P` | `P` |
| **Voltar ao Menu (no Pause)** | `M` ou `ESC` | `M` ou `ESC` |
